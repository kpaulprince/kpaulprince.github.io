Featured work · Ford Motor Company Canada

Building a resilient ECG test platform

Five connected pieces, built between 2023 and today. Pick one to see what it involved — the full project breakdowns will live on the Projects page as the site grows.

DUT health & operations

Keeping DUTs connected, licensed and patched

Monitoring and recovery workflows for the things that quietly take a DUT out of service — so problems surface and get fixed before a test run depends on that DUT.

  • Connectivity — monitoring and recovery for DUT connection issues
  • Token availability — watching for the token problems that block jobs
  • Windows Update status — tracking patch state across DUTs
  • Connection monitor — reads disconnect / reconnect events directly from Jenkins logs
  • Hardware setup automation — automated hardware setup on the DUTs as part of lab & environment automation
Database architecture & cloud migration

An ECG analytics database, designed locally and moved to GCP

The platform needed one place where ECG test data could be analysed across teams, instead of living in scattered lab outputs.

  • Designed locally — the ECG analytics database schema and architecture built from the ground up
  • Migrated to GCP — moved to Google Cloud Platform so teams beyond the lab can use it
  • PostgreSQL — the database technology underneath the analytics store
  • Shared foundation — the data layer the dashboards and Copilot agent both draw on
Grafana dashboards

Dashboards that make test data visible at a glance

Grafana dashboards over the ECG analytics data, so teams can see test health themselves instead of asking the lab team to dig.

  • Brought online locally — first stood up on local infrastructure
  • Migrated to GCP — moved to Google Cloud Platform alongside the database
  • Self-serve visibility — analytics data readable across teams
Jenkins resilience & capacity

Rebuilt Jenkins from the ground up after it was deleted

When Jenkins was accidentally deleted, I rebuilt it from scratch — and used the rebuild to make sure a single accident couldn't take it down the same way again.

  • Full rebuild — Jenkins reconstructed from the ground up after an accidental deletion
  • Redundancy & recovery — measures added so the service can be restored, not reinvented
  • Capacity upgrades — storage and memory increases to support the workload
  • Administration — ongoing Jenkins administration, jobs and CI/CD
ECG Test Analytics Copilot agent

AI-assisted access to ECG test data

A Copilot agent built specifically for ECG test analytics, so people can extract the data they need in plain language instead of writing queries or filing requests.

  • Domain-specific skills — built for ECG test data, not generic chat
  • Prompts & scripts — the extraction logic behind the agent
  • Who uses it — Test Triage, AI bots and test teams
  • What it does — data extraction from the ECG analytics platform
8+ hours → under 30 minutes

Lab & environment automation. Automating VM and prerequisite installation (Python, Bash, Batch, VirtualBox) and hardware setup on the DUTs cut environment setup from a full working day to under half an hour — for a team of 200+ users across 300+ lab machines supporting 300+ DUTs.
